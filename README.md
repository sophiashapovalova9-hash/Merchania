# Merchania

Учебный маркетплейс авторского мерча: витрина на React и API на Node.js + Express.
База данных — SQL Server (`ArtistMerchDB`).

## Как устроено

- `frontend/` — сайт, который открывается в браузере.
- `backend/` — API: товары, корзина, заказы, кабинет художника. Без базы работает в режиме `MOCK_DB=true`.
- `db/` — образ SQL Server, который сам создаёт таблицы при первом запуске.
- `docker-compose.yml` — поднимает базу, API и сайт одной командой.
- `.github/workflows/build.yml` — GitHub Actions: тесты, затем сборка Docker-образов в GHCR.

Практическое занятие №15: контейнеризация и CI. Пошаговая инструкция — в `ПРАКТИКА_15.md`.
